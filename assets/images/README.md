# Identité visuelle d'أثر

`athar-icon.png` et `athar-adaptive-foreground.png` sont des créations originales produites pour ce projet le 1er août 2026 avec l'outil d'image intégré d'OpenAI. Elles ne proviennent pas d'une application, d'une photothèque ou d'un logo tiers.

Le symbole associe une trace lumineuse abstraite, une forme végétale et un rythme de pages, sans texte religieux ni représentation figurative. La variante adaptative est dérivée du même symbole puis détourée localement ; elle sert de premier plan Android et d'image de démarrage.

Palette : vert profond `#173E34`, ivoire `#FAF7EF`, or mat `#AA8741`.
